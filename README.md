# 全球FDE实战

从概念的早期记录到全球行业现场。

FDE（Forward Deployed Engineer，前线部署工程师）如何从一个岗位名称，发展成一类连接客户问题与工程交付的工作方式？它在哪些条件下有效，又何时不值得投入？

本书面向企业负责人、产品与技术负责人，以及准备进入 FDE 的实践者。沿着历史、组织、项目、行业与地区展开，兼顾经营与技术，也为非技术读者解释必要概念。

**[开始阅读：技术到门口以后](chapters/C00.md)** · [在线阅读](https://pafa.github.io/global-fde/) · [阅读索引与术语](appendix/reading-guide.md)

这一公开版本整理于 2026 年 9 月，资料截止 2026-09-25。案例保留来源与可知范围，明确区分公司陈述、研究判断和教学示例。欢迎读者指出错漏、提供反证，让这本书持续修订。
