# C28：带走未完成的工作，也核清继续使用的权利

这是合成退出演练，不是合同范本或法律意见。[三项中间任务](pending-tasks.json)发生在旧写入和发送队列已停止、新系统不自动执行的测试切换点T。

T01没有批准，导入不会补上批准。T02已有针对版本5的批准，负责人要核对新环境和原执行对象相符后才接续。T03可能已经产生业务效果，本题按旧动作A03查到E03，只补回执，不能再执行一次。查询仍不确定时，停在待核升级。

[许可对象矩阵](rights.csv)另列五种对象。适配代码可使用，不意味着供应商平台代码已移交；第三方组件L未核清，因此整体切换仍被阻断。三个工单解释清楚不能替代许可与运行验证。

用[空白表](migration-blank.csv)增加一个“已批准但内容又被修改”的任务。预期是保留旧批准的历史，但重新批准当前版本；不要改旧记录使其看上去从未发生。最后分别检查运行、权利和撤权，写清通过范围。任何真实账号撤权、数据处置须遵项目授权和适用约定，本包不执行这些操作。
