# C08：三题不能证明可靠，但能推翻一个错误评分办法

[完整样本](cases.json)包含资料、三段预设输出与教学裁决；[分歧记录](adjudication.csv)把E2为什么从通过改为不通过单列。没有运行真实模型，没有真人专家意见，链接使用不可访问的example.invalid，避免被当成公共服务入口。

做法：先独立按D2判断三段输出，再看评分器结论。E2即使给出了入口，也凭空补了事项和资格；专家判不通过的根据在源资料，不在专家身份本身。修改评分规则为G2以后，必须重评三题；不能只手工扣E2分就宣布评分器校准完成。

示范发布决定：r3仅员工预览，E2/E3转原人工渠道；任何直出公众都违反当前范围。假定下一小时复核容量5条，积压达到6条暂停新进件。可替代选择是完全暂缓试用、先修r4；若选择继续预览，就必须保留真实可用的复核人。三题结果不支持准确率百分比，也不代替真实流量验证。

复用[空表](evaluation-blank.csv)时写实际来源、配置与输出，避免把此处模拟结果当作你自己系统的测试记录。资料和模型有实质变化后，旧判断不能自动延续。
