# C06：18、36、18、16分别怎么来的

所有机构、值、时间和定义均为教学数据，不是医疗操作指南。[reports.csv](reports.csv)的r1在12点被收到，r2在14点才确认替代；T为同一合成日。读取某次历史发布时，只能使用当时已接收且有效的版本，不能把今天知道的r2倒灌回P1。

1. 打开[原始报告](reports.csv)和[联系人](contacts.csv)。一份r1加两位联系人，错误连接会生成[两行18](wrong-join.csv)，求和36。
2. 正确做法按统计单位选一份报告，先算数，再附联系人。不要简单除2，也不要按数值去重；另一家机构也报18时仍须保留它。
3. 看[发布记录](publications.csv)：P0=36为错误，P1=18修复连接，P2=16应用源头更正。B未报，因此覆盖1/2；未知没有变成零。
4. 用[契约](contract.json)的六项预期做讨论。r2若未确认，先待核，不能凭收到较晚便使用。实际程序需要据此实现检查，本包不声称已经运行生产程序。

选择路线：单张日报可用映射表与版本选择程序；多个应用共同维护对象和更正动作时再比较对象层。两者都要履行同一份数据契约，选更重平台不会自动解决口径。

[空白契约](contract-blank.csv)供自己的数据负责人、工程人员和使用者共同填。不要把本练习D1冒充真实床位口径；真实医疗定义应由合适机构和专业人员确定。
