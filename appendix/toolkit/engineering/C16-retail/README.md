# C16：从下单追到同批交易净贡献

这15笔[交易](transactions.csv)完全合成，不是OTTO数据。A、B各100次购物机会；未下单机会仍留在分母。[假设](assumptions.json)固定观察窗口和费用口径。

先求每组订单与收入，再扣同批退货：A保留900元，B保留450元。商品毛利只扣货物成本；履约、退货处理、客服和AI单列，不能重复扣。CSV每行净贡献可相加，得到A 160元、B 20元。两组均未减公司固定成本，所以不是公司净利润。

[敏感性](sensitivity.csv)保持B客服30、AI25等教学条件，B达8单且退1单时贡献186，高于A；7单且退1单时只有149。该计算回答“哪些变化可能使方案值得继续”，不能证明入口导致这些订单。

先填[空表](cohort-blank.csv)，再做一个修改：把退货商品改为只能折价再售。需另计减值，不能仍沿用本包贡献。经营决定应同时看交易质量与费用；本例B当前先暂停扩大范围，排查退货原因，不因平均订单金额较高就扩大部署。
