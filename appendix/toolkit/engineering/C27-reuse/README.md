# C27：让第二个客户增加能力，而不破坏第一个

[兼容表](compatibility.csv)列8项预期，实际结果均为`not_run`；没有冒充客户测试。[策略](policies.json)规定v1只支持A，v2要求明确选择策略。B仅覆盖本题夜间特殊区，不凭空补其他业务规则。

先检查A1、A2，再检查B。反例“全局白天免审批”即使让B某个演示更顺畅，也会使A1失守。批准后改变时间或区域，要增加任务版本并重新审批；退回旧程序时同步恢复匹配配置。

[产品决定](product-decision.json)展示一个合法、能做、有人愿付钱，却暂不应进入公共产品的打印请求。接受有维护安排的客户扩展；未确认维护则保留人工步骤。它不是拒绝客户，也不是无限免费定制。

在[空表](migration-blank.csv)中增加第三家客户前，写清原承诺、变化、谁接收长期维护。实际运行该策略所需代码与客户批准不在本包中；这是一份可供团队逐条实现和验证的接口约定。
