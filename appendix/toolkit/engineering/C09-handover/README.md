# C09：让接手者完成下一次资料变化

[已填演练](exercise.json)是一份合成记录，不是实际客户训练成果。手册只描述适用范围，不含真实维修指令。练习在隔离环境进行，不接生产数据、通知或设备。

把观察者与动手者分开。先让接手者读任务、权限和文档状态，设计变更；观察者只提示已存在的指南位置，不指出每一个正确按钮。第一轮示例失败在漏停V1，不能用“V2上传成功”关闭任务。第二轮同时测X1、X2与旧链接，然后由有权者决定发布。

合理求助不扣成失败：适用型号由业务专家确认，底层平台故障向供应商升级。无法自行发布也不是能力不足，只要变更记录能交给有权负责人。真正的失败是越权、掩盖未知、跳过旧版本影响或没有把结果交给下一人。

[空白记录](rehearsal-blank.csv)用于另一位接手者复做。通过只限实际演练的动作，别据此宣称已经完全离场；可以选择延长共同维护，但要写明缺的是哪种能力，以及下一次怎样观察。
