# C26：同一份80万元合同的两边

全部数字为教学假设。供应商项目有三种观察口径：58万元直接及归集成本；加入12万元获客和15万元共享分摊后85万元宽口径成本；58＋12＝70万元可识别现金支付。不得把三种口径混为法定净利润。

## 从哪里算起

- [完整双方账](ledger.csv)：从未扩范围的基线算起。客户支付的80万元就是供应商合同收入，不能合并双方后当作两笔社会收益。客户观察期是上线后12个月；供应商58万元覆盖一期部署。客户后续12万元运行费是不同期间，不与部署4万元重叠。
- [现金安排](supplier-cash.csv)：同一基线改看收付款，月份相对签约。最低月末累计值-12万元；把第二月36万元移到第四月，最低月末值变成-46万元，期末仍是10万元。没有给15万元分摊虚构支付日期；月内支付顺序未知，不能把月末最低值当作逐日资金峰值。
- [条件与继续决策](assumptions.json)：先核对人日、费率与外包替代假设。比较继续／缩小／退出时，转到已增加设备类型的93万元成本分支，只比较从当前时点往后的收入和投入，不与58万元基线混算。
- [单项与组合敏感性](sensitivity.csv)：回到未扩范围的基线，资源4万元中1万元固定、3万元线性随调用量变化。人员费不随调用量自动翻倍；额外返工10天按3000元/天单列。

## 示范答案

供应商基线宽口径剩余80−85＝−5万元。客户经济投入80＋6＋2＋12＝100万元；新增现金94万元。确认取消的外包采购400×200×12＝96万元，因此经济差额−4万元、现金差额＋2万元。月净省时10000×(6−2)/60＝666.67小时，未被外包替代的266.67小时没有再折算现金。质量、等待与积压改善应另观察。

改成每月只少采购300小时，少支出72万元，经济差额−28万元。若仍扩张，负责人应说明为何非现金改善值得28万元，或先缩小服务范围验证。另一种合理选择是延长观察，但必须先确认后续12万元服务费是否继续发生，不能免费多加一年收益。

复用时填 [空账](ledger-blank.csv)，逐行注明证据、期间和是否已在另一项计过。经营负责人负责收益和范围，技术负责人解释调用与返工，客户负责人确认真正取消的采购。不能用本例费率替真实报价，也不能把人员空出的时间直接当作裁员节省。
