# C15：两单两车，算出可执行的取舍

全部数据为合成教学，未调用运输平台。先读[订单](orders.csv)、[车辆](vehicles.csv)和[行车时间](travel.csv)，自己写出最低成本可行方案，再打开[已填方案](plans.json)。时间窗口指开始卸货；不要求卸货在窗口内结束。可以提前到达并等待，但不能在货物备好前离仓。

先选中候选方案P3，计划由V1在13:30带两单离仓，先O2后O1，成本80，O1剩5分钟余量。单独派车P4成本130，更宽松。P1违反载重和人数，P2的O2晚50分钟。

上述发车计划尚未执行。到13:35，仓库才确认V1最早13:50才能离仓；两单都尚未装车，原方案P3因此失效。仓库确认O2解除原分配后，选P6，成本130，O1余量变为0。不要把同一货物同时写在两车清单中。

用[空白决定表](decision-blank.csv)练习：把O2备好时间改为13:50，哪些方案还可行？V2最早14:10到O2，原窗口不成立；模型不能擅自延长窗口。需要客户同意改约、另一种经验证的资源，或拒绝承诺。修改假设时保留原版，不把更宽窗口当原承诺下的改善。

本包不含交通随机性、装货时长、回程或法规约束；新增这些条件可能推翻当前最优解。实际项目须核对当地真实约束。
