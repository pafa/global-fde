# C25：一周排期怎样限制新的承诺

这是一个合成维修项目，小时数不是行业编制。[已填排期](week.csv)按角色求和：FDE40、客户系统工程师12、维修主管6、产品联系人另4。CSV的可投入总数按角色重复展示，不能逐行求和当新增容量。

[第二区域决定](request-decisions.json)写明两地同时上线还缺16、6、2小时；选择推迟R2。替代方案只在主管同意顺延R1开发、当地观察条件到位后，把FDE开发18改14，腾出4小时观察。总量仍40，没有上线承诺，也没有悄悄拿走异常响应预留。

用[空表](week-blank.csv)改一项：若FDE本周请假8小时，现有40小时承诺已经超出容量。明确推迟工作或增加可靠代班，再讨论R2；不要用“提高效率”自动填平缺口。产品联系人负责公共能力判断，不代替客户主管决定业务范围。
