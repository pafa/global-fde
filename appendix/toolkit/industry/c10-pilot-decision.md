# 试点决策单：两馆维修查询

工具编号 TK-C10-01。对应[第22章 公共部门与国防：任务、采购和问责](../../../chapters/C10.md)。下面的机构、数量与结果全部虚构，仅用于练习公共项目的范围与责任分配，不是法定采购表格。

## 怎么用

先写一个能被使用者完成的任务，再用已有记录核对当前缺口。填写“已验证”时附证据位置；还没执行的检查留为计划。技术修复、业务恢复和新增采购由各自有权的人决定。一轮结束保留旧决定，不覆盖成后来结果。

## 已填例子：P-01，第五个工作日的状态

| 字段 | 已填记录 |
| --- | --- |
| 任务 | 甲、乙两馆查询已有设备工单的状态、责任人、更新时间 |
| 范围 | 两馆、只读、五个工作日，两馆各十笔去重测试工单 |
| 不做 | 选择维修商、批准支出、设备安全判断；不展示邮件正文和个人联系方式 |
| 输入 | 甲 A01—A10，乙 B01—B10；各馆数据负责人保存原件位置并确认更新责任 |
| 路线比较 | 现有工单系统可配置字段及权限；内部信息团队承接，暂无新增平台或驻场采购 |
| 核验 | 每笔对工单号、状态、更新时间；测试已撤销、未验收记录；另测重复编号，不重复计入20笔工单；馆员能说出下一联系人 |
| 发现 | 甲十笔通过；乙因字段改名漏 B03、B08，不能用访问量抵消缺失 |
| 当前决定 D1 | 甲继续有限试用；乙暂停，页面标不可用，恢复旧查询 |
| 修复与恢复条件 | 工程师修映射；乙数据负责人重新核十笔；主管确认后才能恢复；目前仍待复核 |
| 扩大采购条件 | 新范围、缺口、持续维护与替代方案成本齐备，采购负责人依适用程序决定；目前未达到 |
| 下一检查 | 第六个工作日由信息团队交修复证据，乙负责人核验；未通过则保持暂停 |
