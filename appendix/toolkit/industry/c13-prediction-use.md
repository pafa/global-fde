# 从警报到采用：保留每一步的分母

工具编号 TK-C13-01。对应[第26章 制造与航空：工程师必须理解生产](../../../chapters/C13.md)。数字完全虚构，不是easyJet结果，也不提供设备维修阈值。下载[已填CSV](c13-prediction-use-example.csv)。

## 怎么用

先固定设备范围和观察窗口，对警报去重。逐条记录是否值得检查、是否具备行动窗口、完成检查后发现什么。每个比例写明分母；未检查不等于误报，无后续故障不等于避免故障。

## 已填例子

同一设备范围、四周，共20条去重警报。12条经专业人员判断值得安排检查；9条在窗口内完成，其中6条发现需处置问题、3条未发现本次所查问题。另3条待检查：两条因没有合适窗口，一条等待资源。其余8条在初筛阶段未安排检查，仍需保留理由，不都称误报。

| 指标 | 记录 |
| --- | --- |
| 初筛进入检查安排 | 12/20 |
| 检查按窗口完成 | 9/12 |
| 已检查中发现需处置问题 | 6/9 |
| 全部警报的调查时间 | 8小时，含初筛与检查协调，单独记账 |
| 为检查预留但未使用的备件 | 2件，各占用7天；不直接折算现金成本 |
| 无警报却故障的对象 | 尚未完成独立记录，漏报率未知 |
| 当期决定 | 先处理三条待检查任务及窗口限制，不根据6次发现声称避免6次停机 |
