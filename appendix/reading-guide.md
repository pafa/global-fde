# 阅读索引：先作哪项判断，再去哪里找证据

第一次读，先从[序章](../chapters/C00.md)进入，再依次读概念与模式的四章：[名称与前史](../chapters/C01.md)、[Palantir的现场与产品](../chapters/C02.md)、[平台与服务伙伴](../chapters/C03.md)、[模型与交付变化](../chapters/C04.md)。接着用[团队组成](../chapters/C25.md)和[项目经济性](../chapters/C26.md)回答“由谁承担、为什么值得做”，再沿[发现问题](../chapters/C05.md)、[数据含义](../chapters/C06.md)、[可靠运行](../chapters/C07.md)、[上线评估](../chapters/C08.md)、[采用与接手](../chapters/C09.md)走过一次项目，进入[产品复用](../chapters/C27.md)。

有了这些工具，再读行业实践（从[公共部门](../chapters/C10.md)至[科研与教育](../chapters/C20.md)）和地区条件（从[欧美](../chapters/C21.md)至[其他地区的具体实践](../chapters/C24.md)），比较同一种工作为何在不同环境中改变。最后用[边界与退出](../chapters/C28.md)、[职业能力](../chapters/C29.md)、[Agent带来的变化](../chapters/C30.md)回看自己的选择，以[结语](../chapters/C31.md)收束。

## 三条可选路线

| 你的任务 | 建议路线 | 读完先作一项判断 |
| --- | --- | --- |
| 企业是否值得投入、由谁承担 | [概念边界](../chapters/C01.md) → [问题发现](../chapters/C05.md) → [团队](../chapters/C25.md) → [两边的项目账](../chapters/C26.md) → [退出](../chapters/C28.md) | 写出一个可与FDE比较的替代方案，算入客户自己的投入 |
| 把演示变成可运行的工作 | [发现](../chapters/C05.md)、[数据](../chapters/C06.md)、[运行](../chapters/C07.md)、[评估](../chapters/C08.md)、[接手](../chapters/C09.md) → [复用](../chapters/C27.md) | 沿一次实际任务，标出资料、授权、异常与下一位责任人 |
| 准备进入FDE岗位 | [概念与模式：C01—C04](../chapters/C01.md) → [项目过程：C05—C09](../chapters/C05.md) → [能力与作品](../chapters/C29.md) | 完成一个有异常、有修改记录的作品，再找真实使用者检验 |

C编号是固定的查找标识，目录按阅读顺序编排。表中的编号范围需要依次阅读，链接指向组内起始章；这与序章和网站导航中的路线一致。走完后，再选择一个熟悉行业和一个陌生行业，并查看相应地区条件；需要评估长期投入时，可回读团队、经营、退出和未来章节。

## 手头有一项工作，直接从这里开始

这些样例都明确标为教学，包含一份填好的记录和可复制空表；它们帮助讨论与练习，不是任何行业的统一制度。先看示范如何作决定，再替换成自己的依据，不把示范数字当目标。

| 正在做的事 | 正文定位 | 已填样例与用法 |
| --- | --- | --- |
| 确认是否启动或扩大试点 | [公共采购与问责](../chapters/C10.md)“沿一条报修查询请求分配责任” | [两馆试点决策单](toolkit/industry/c10-pilot-decision.md)：甲馆有限继续、乙馆暂停，当前不扩大采购 |
| 发现资料错了，追查影响 | [金融纠错](../chapters/C12.md)“错误要有能走回去的路” | [A-17更正记录](toolkit/industry/c12-correction-record.md)：旧文件、摘要、决定、工程修复与重新裁决 |
| 核实省时是否被新增负担抵消 | [医疗工作量](../chapters/C11.md)“省下的时间，原来花在谁身上” | [工作量记录](toolkit/industry/c11-workload-record.md)：同路径、等长窗口，减少与新增分开 |
| 算客户与供应商的收益和成本 | [项目经济性](../chapters/C26.md)“一笔可以逐项检查的项目账” | [双方账与敏感性示例](toolkit/engineering/C26-economics/README.md)：现金、人员时间和分摊口径分别算 |

## 容易卡住的词，先这样理解

下表解释本书讨论中的用法，不代替具体供应商的产品文档。遇到同一个词在不同项目中含义不同时，以该章写明的对象与条件为准。

| 词语 | 普通语言解释 | 继续读 |
| --- | --- | --- |
| FDE | 前线部署工程师。贴近客户实际工作并承担工程交付；不同公司的职责和产品反馈安排并不相同。 | [序章](../chapters/C00.md)、[概念边界](../chapters/C01.md) |
| Agent | 能调用软件工具、推进任务的 AI 程序。能生成答案与有权执行动作，需要分别判断。 | [序章](../chapters/C00.md)、[可靠运行](../chapters/C07.md) |
| Deployment Strategist | 部署策略岗位。相关 Palantir 材料里涉及问题发现与工作安排；不要据英文名称推定所有公司的职责相同。 | [Palantir的现场与产品](../chapters/C02.md) |
| 基线 | 改变之前或用于比较的工作方式及其表现。没有比较对象，很难知道改善了哪一步。 | [问题发现](../chapters/C05.md) |
| 业务语义 | 一个字段或状态在工作中究竟表示什么。两个系统都写“库存”，可能并未计算同一种数量。 | [数据含义](../chapters/C06.md) |
| 本体／Ontology | 用对象、它们的关系和相关动作表达业务的一种方式。本书不把产品术语直接等同全部哲学或计算机学科用法。 | [数据含义](../chapters/C06.md) |
| API／接口 | 程序之间交换信息或请求动作的约定入口。调用成功，还要继续确认业务是否真正完成。 | [可靠运行](../chapters/C07.md) |
| MCP | Agent 寻找、调用外部工具的一套连接约定。连得上工具，不表示已获得完成任意业务的权限。 | [模型与工程变化](../chapters/C04.md) |
| 工具调用 | AI 程序请求另一个软件功能执行某件事；请求、实际执行和结果回传是不同环节。 | [可靠运行](../chapters/C07.md) |
| 原生音频 | 在所讨论的系统中直接处理或生成音频的能力。具体支持什么、如何接入，以该章所引产品资料为准。 | [可靠运行](../chapters/C07.md) |
| Live API | 运行章节所述实时交互接口。它是具体产品的名称，不是对所有实时系统的统称。 | [可靠运行](../chapters/C07.md) |
| 评估／Evals | 用一组任务与判断规则检查系统表现。总分之外，还要看错误会影响谁、发生在哪类任务。 | [上线评估](../chapters/C08.md) |
| 生产环境 | 系统实际承担日常工作、其结果会被使用的环境。与展示、试验环境分开记录。 | [可靠运行](../chapters/C07.md)、[上线评估](../chapters/C08.md) |
| 上线、采用、成效 | 上线是可进入实际运行；采用是有人在使用；成效还要证明工作或结果发生了什么变化。具体范围不能省略。 | [采用与接手](../chapters/C09.md) |
| 连接器 | 帮助一套系统与另一套系统交换数据或动作的软件部件。连接完成后，含义、权限和维护仍需安排。 | [数据含义](../chapters/C06.md)、[团队组成](../chapters/C25.md) |
| 编排 | 给多个动作规定先后、条件和交接。每个动作单独正确，不保证组合起来也正确。 | [金融纠错](../chapters/C12.md)、[Agent带来的变化](../chapters/C30.md) |
| 回滚／恢复 | 变更不符合预期时，恢复到能够继续服务的状态；已经发生的业务后果不一定能随软件一并撤销。 | [上线评估](../chapters/C08.md)、[退出与恢复](../chapters/C28.md) |
| 百分比与百分点 | 从 50% 到 67%，相差 17 个百分点；它不等同于在原来数值上增加 17%。比较时先看分母和测量对象。 | [Agent带来的变化](../chapters/C30.md) |
| 统计显著性 | 按研究采用的统计方法，判断观察到的差异在假设没有真实差异时是否罕见。结果依赖方法、样本与门槛；未达到标准，不等于证明完全没有差别。 | [Agent带来的变化](../chapters/C30.md) |
| 同源材料 | 几份材料可能来自同一项目、数据或发布者。转述次数增加，不等于获得了更多独立验证。 | [序章](../chapters/C00.md)及各章注释 |
| 固定总价与按结果收费 | 前者先约定一项工作的价格，后者把收费与合同定义的结果挂钩；前者不自动等于后者。 | [项目经济性](../chapters/C26.md) |

## 怎样追查依据

各章注释直接链接原件，并列出日期、相关位置和证据限制。需要跨章查找时，可从本页的[行业章节指引](#按行业找具体困难)进入相关章节，再沿脚注查阅原始来源；有关明确 FDE、相似交付与相邻实践的区别，参见[第1章](../chapters/C01.md)。计划、试点、上线与结果披露须按各章所列日期和范围分别理解。

研究截止日为 2026 年 9 月 25 日。动态岗位和产品页只证明所记录访问时的内容；历史说明保留原来的发生和披露时间。书中的教学情境与算例用于解释选择，不作为真实客户的经历、投入或效果。
