# 阅读索引：先作哪项判断，再去哪里找证据

第一次读，先从[序章](../chapters/C00.md)进入，再读[概念、前史与当下变化：第1—4章](../chapters/C01.md)。接着用[团队：第25章](../chapters/C25.md)和[项目经济性：第26章](../chapters/C26.md)回答“由谁承担、为什么值得做”，再沿[第5—9章](../chapters/C05.md)完成发现问题、数据、运行、评估与接手，进入[产品复用：第27章](../chapters/C27.md)。

有了这些工具，再读[行业实践：第10—20章](../chapters/C10.md)和[地区条件：第21—24章](../chapters/C21.md)，比较同一种工作为何在不同环境中改变。最后用[边界与退出：第28章](../chapters/C28.md)、[职业能力：第29章](../chapters/C29.md)、[Agent带来的变化：第30章](../chapters/C30.md)回看自己的选择，以[结语](../chapters/C31.md)收束。

## 容易卡住的词，先这样理解

下表解释本书讨论中的用法，不代替具体供应商的产品文档。遇到同一个词在不同项目中含义不同时，以该章写明的对象与条件为准。

| 词语 | 普通语言解释 | 继续读 |
| --- | --- | --- |
| FDE | 前线部署工程师。贴近客户实际工作并承担工程交付；不同公司的职责和产品反馈安排并不相同。 | [序章](../chapters/C00.md)、[第 1 章](../chapters/C01.md) |
| Agent | 能调用软件工具、推进任务的 AI 程序。能生成答案与有权执行动作，需要分别判断。 | [序章](../chapters/C00.md)、[第 7 章](../chapters/C07.md) |
| Deployment Strategist | 部署策略岗位。相关 Palantir 材料里涉及问题发现与工作安排；不要据英文名称推定所有公司的职责相同。 | [第 2 章](../chapters/C02.md) |
| 基线 | 改变之前或用于比较的工作方式及其表现。没有比较对象，很难知道改善了哪一步。 | [第 5 章](../chapters/C05.md) |
| 业务语义 | 一个字段或状态在工作中究竟表示什么。两个系统都写“库存”，可能并未计算同一种数量。 | [第 6 章](../chapters/C06.md) |
| 本体／Ontology | 用对象、它们的关系和相关动作表达业务的一种方式。本书不把产品术语直接等同全部哲学或计算机学科用法。 | [第 6 章](../chapters/C06.md) |
| API／接口 | 程序之间交换信息或请求动作的约定入口。调用成功，还要继续确认业务是否真正完成。 | [第 7 章](../chapters/C07.md) |
| 工具调用 | AI 程序请求另一个软件功能执行某件事；请求、实际执行和结果回传是不同环节。 | [第 7 章](../chapters/C07.md) |
| 原生音频 | 在所讨论的系统中直接处理或生成音频的能力。具体支持什么、如何接入，以该章所引产品资料为准。 | [第 7 章](../chapters/C07.md) |
| Live API | 第 7 章所述实时交互接口。它是具体产品的名称，不是对所有实时系统的统称。 | [第 7 章](../chapters/C07.md) |
| 评估／Evals | 用一组任务与判断规则检查系统表现。总分之外，还要看错误会影响谁、发生在哪类任务。 | [第 8 章](../chapters/C08.md) |
| 生产环境 | 系统实际承担日常工作、其结果会被使用的环境。与展示、试验环境分开记录。 | [第 7 章](../chapters/C07.md)、[第 8 章](../chapters/C08.md) |
| 上线、采用、成效 | 上线是可进入实际运行；采用是有人在使用；成效还要证明工作或结果发生了什么变化。具体范围不能省略。 | [第 9 章](../chapters/C09.md) |
| 连接器 | 帮助一套系统与另一套系统交换数据或动作的软件部件。连接完成后，含义、权限和维护仍需安排。 | [第 6 章](../chapters/C06.md)、[第 25 章](../chapters/C25.md) |
| 编排 | 给多个动作规定先后、条件和交接。每个动作单独正确，不保证组合起来也正确。 | [第 12 章](../chapters/C12.md)、[第 30 章](../chapters/C30.md) |
| 回滚／恢复 | 变更不符合预期时，恢复到能够继续服务的状态；已经发生的业务后果不一定能随软件一并撤销。 | [第 8 章](../chapters/C08.md)、[第 28 章](../chapters/C28.md) |
| 百分比与百分点 | 从 50% 到 67%，相差 17 个百分点；它不等同于在原来数值上增加 17%。比较时先看分母和测量对象。 | [第 30 章](../chapters/C30.md) |
| 统计显著性 | 按研究采用的统计方法，判断观察到的差异在假设没有真实差异时是否罕见。结果依赖方法、样本与门槛；未达到标准，不等于证明完全没有差别。 | [第 30 章](../chapters/C30.md) |
| 同源材料 | 几份材料可能来自同一项目、数据或发布者。转述次数增加，不等于获得了更多独立验证。 | [序章](../chapters/C00.md)及各章注释 |

## 怎样追查依据

各章注释直接链接原件，并列出日期、相关位置和证据限制。需要跨章查找时，可从本页的[行业章节指引](#按行业找具体困难)进入相关章节，再沿脚注查阅原始来源；有关明确 FDE、相似交付与相邻实践的区别，参见[第1章](../chapters/C01.md)。计划、试点、上线与结果披露须按各章所列日期和范围分别理解。

研究截止日为 2026 年 9 月 25 日。动态岗位和产品页只证明所记录访问时的内容；历史说明保留原来的发生和披露时间。书中的教学情境与算例用于解释选择，不作为真实客户的经历、投入或效果。
